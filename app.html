怎么拿 API Key？
  1. 打开 platform.deepseek.com，注册（手机号就行）
  2. 充 10 块钱 —— 按实测用量，一节课大约几毛钱，够上很久
  3. 左边「API keys」→ 创建一个 → 复制那串 sk- 开头的
  4. 粘到上面的框里，点「测试连接」

Key 只存在你自己浏览器的 localStorage 里，不会发给任何第三方。
但要注意：浏览器直连模型服务，你的 key 会出现在网络请求里，别在公用电脑上用。
